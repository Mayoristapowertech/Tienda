# POWERTECH - Demo de tienda

## Publicar en GitHub Pages

1. Crear un repositorio público en GitHub.
2. Subir `index.html`, `style.css`, `script.js` y opcionalmente `logo.png`.
3. Entrar en **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama `main` y carpeta `/ (root)`.
6. Guardar y esperar a que GitHub publique la página.

## Personalizar productos

Los 6 productos y los 3 combos están en `script.js`, en las variables `productos` y `combos`.

## WhatsApp

El número está en:
`const TELEFONO_WHATSAPP = "5491171388777";`

Cambialo si necesitás utilizar otro número.

## Compra mínima

Está configurada en:
`const COMPRA_MINIMA = 50000;`

El carrito no permite finalizar por WhatsApp hasta llegar a ese importe.

## Imágenes

La demo utiliza emojis como imágenes de producto para que funcione inmediatamente sin depender de archivos externos. Podés reemplazarlos posteriormente por fotos reales.
